# Pets

A beginner C# console application for managing pet information in the Contoso PetFriends app.

## Run the app

From this project folder, run:

```powershell
dotnet run
```

## Features

- List current pet information
- Add a new dog or cat
- Store each pet's age, nickname, physical description and personality
- Exit the application by typing `exit` (case insensitive)

The application can manage up to eight pets at a time.

## Project

This project targets .NET 10 and uses a two-dimensional string array to store pet records.
